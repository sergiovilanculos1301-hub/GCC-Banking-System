# GCC Banking System

## Introduction
The GCC Banking System is a simple banking application developed using C++. It was created for the Introduction to Programming NQF Level 4 assignment at Gauteng City College.

## Features
The program allows users to:
- Log in using an account number and PIN.
- Deposit money.
- Withdraw money.
- Send cash to another registered account.
- Check account balances.
- Exit the banking system.

## Programming Concepts Used
- Functions
- Arrays
- If and else statements
- Switch statements
- Do-while loops
- Input validation

## Registered Users
The program contains three sample users:
- John
- Peter
- Mary

## How to Run
1. Open the project in Code::Blocks.
2. Build and run the program.
3. Enter a valid account number and PIN.
4. Select an option from the banking menu.

## Programming Language
C++

## Development Environment
Code::Blocks with GNU GCC Compiler.

## Author
Gauteng City College Student

## Purpose
This project demonstrates the use of basic programming concepts to develop a simple command-line banking system.
